# Contributing to Choicer Voicer Pack Studio

Thank you for your interest in contributing to **Choicer Voicer Pack Studio**! 🙌

## 🌟 Ways to Contribute

1. **Reporting Bugs:**
   - Open an issue on GitHub with a clear description, your operating system, and reproduction steps.
2. **Feature Requests:**
   - Share ideas in Discord or open a feature request issue on GitHub.
3. **Submitting Code (Pull Requests):**
   - Fork the repository.
   - Create a new feature branch: `git checkout -b feature/my-feature`.
   - Test your changes locally with `python main.py`.
   - Submit a pull request with a descriptive summary.

## 🛠️ Code Style & Guidelines

- Use **Python 3.10+** with clean type annotations (`typing`).
- Keep the user interface responsive (run heavy tasks like AI vocal isolation and video conversion in background threads via `QThread`).
- Follow the Cyber-Cyan Dark Theme styling of *The Choicer Voicer*.

Thank you for making the community tool better! 🚀
